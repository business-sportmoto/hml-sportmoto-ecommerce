# Leia primeiro

Este Vault documenta o projeto de e-commerce SportMoto.

## Antes de qualquer alteração

1. Analise os arquivos reais.
2. Localize o fluxo atual.
3. Identifique dependências.
4. Confirme tabelas e colunas existentes.
5. Não suponha que uma documentação planejada já esteja implementada.
6. Diferencie:
   - existente;
   - em desenvolvimento;
   - planejado;
   - legado;
   - descontinuado.

## Fontes de verdade

- Código atual: implementação real.
- Banco atual: estrutura real de dados.
- Vault: contexto, histórico e decisões.
- `CLAUDE.md`: regras obrigatórias de trabalho.

Em caso de divergência entre documentação e código, não decida silenciosamente. Informe a divergência.
